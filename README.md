# Restaurant Management System (Salesforce)

A Salesforce app with 10 custom objects for managing restaurant operations.

## Deploy to your own org

    git clone https://github.com/arooba-shafique/restaurant-management-salesforce.git
    cd restaurant-management-salesforce
    sf org login web --alias myorg
    sf project deploy start --source-dir force-app --target-org myorg
